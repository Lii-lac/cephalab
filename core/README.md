# core

The C++20 seed core (contract: `API.md`), built to WebAssembly as `dist/core.mjs` + `dist/core.wasm`.

- Toolchain: Emscripten SDK (`emsdk install latest`, `emsdk activate latest`); set `EMSDK_DIR` if it isn't in `$HOME/tools/emsdk` or on `PATH`.
- Build (Git Bash, any shell, no env setup needed): `bash core/build.sh` (sources emsdk_env itself; ~15 s).
- Test: `node tests/core/run_tests.mjs` (rolls, startSeed, recovery/refine, bad input, timing; prints `RESULT` lines, exit 0 = all pass). Needs `.venv` with `pymmh3` for the Python vectors.
- Brand tables: `core/src/gen/tables.h` is generated by `python core/tools/gen_tables.py` from `data/BrandTraitsParam.raw.json` (re-run after the data changes).
- Sources: `src/seedmath` (xorshift32, rolls), `src/murmur3` (hash, start seed), `src/recovery`, `src/plan*` (planner: `plan_search` one piece, `plan_out` lanes/columns/JSON, `plan_api` parsing), `src/json` (reader/writer), `src/api.cpp` (`st_call`).
- Use from JS: `const M = await (await import('./core.mjs')).default(); const p = M.stringToNewUTF8(req); const out = M.UTF8ToString(M._st_call(p)); M._free(p);`
- Interpretations of API.md: unknown but well-formed brand codes (`B00`..`B99`) use the `None` row, anything else is an error; `drink` may be omitted (= null); `maxSteps` above 2,500,000 is an error (not clamped) and k runs 0..maxSteps inclusive; `observed` must be non-empty; `refine` takes seeds as numbers or `{seed}` objects and drops repeated seeds.
- Test-only fn, not in the contract: `{"fn":"_murmur3","text":...,"seed":...}` returns `{hash}`.
- joint drink scheduling: not yet
